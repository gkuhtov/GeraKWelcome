## 🧭 О проекте

**GeraKStore Welcome** — набор приветственных экранов и компонентов оформления для iOS. В репозитории находятся два направления: WelcomeToSpace и WelcomeToJapan, а также связанные ресурсы, конфигурации и сценарии сборки или внедрения.

## ✨ Варианты оформления

### 🌌 WelcomeToSpace

Космическая визуальная тема с отдельными файлами конфигурации, ресурсов и логики приветственного экрана.

### 🌸 WelcomeToJapan

Тема с японскими визуальными мотивами, включая сакуру и декоративные изображения.

## 🧱 Структура проекта

| Путь | Назначение |
|---|---|
| `WelcomeToSpace/` | Компоненты, конфигурации и ресурсы космической темы |
| `WelcomeToSpace/Resources/Config/` | JSON-конфигурации внешнего вида, текстов и ссылок |
| `WelcomeToJapan/` | Исходники, ресурсы и параметры сборки японской темы |
| `.github/workflows/` | Автоматизированная сборка и сценарии внедрения |
| `.gitignore` | Правила исключения файлов из Git |

## ⚙️ Конфигурация и сборка

В репозитории есть конфигурационные файлы и сценарии GitHub Actions для отдельных вариантов. Перед сборкой проверяйте соответствующий файл workflow и инструкции внутри конкретного каталога.

**Не переименовывайте и не удаляйте исходники, ресурсы, заголовки, JSON-конфигурации, Makefile или workflow без отдельного анализа.** Для подобных компонентов имена и пути могут быть частью механизма сборки и загрузки ресурсов.
